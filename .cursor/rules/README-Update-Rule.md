# Flowly AI 代码规则

## 文档更新要求

**每次更新代码后，必须同步更新 `README.md` 总说明文档。**

具体要求：

1. **新增功能**：在 `README.md` 对应章节中添加功能说明、API 接口或使用示例
2. **修改配置**：更新环境配置、环境变量说明等章节
3. **变更依赖**：在依赖说明章节中更新相关包信息
4. **新增模块/组件**：在项目结构章节中添加对应的目录树说明
5. **Bug 修复**：如有必要，在常见问题章节中补充相关内容

更新原则：
- 保持文档与代码同步，确保 `README.md` 始终准确反映项目当前状态
- 使用清晰的 Markdown 格式，保持文档结构整洁
- API 变更需同步更新接口文档表格
